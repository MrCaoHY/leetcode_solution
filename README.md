## 💡 深度刷题策略

1. **分板块攻克：** 建议一周只攻克 1-2 个板块。比如这周只做“链表”，把那 7 道题做透，总结出“虚拟头节点”和“快慢指针”的通用规律。
2. **注重 Pythonic 的写法：**
* Java 用 `Map` 需要写一堆代码，Python 只需要 `{} `。
* 利用 `collections.deque` 实现高效队列。
* 掌握 `list` 的切片操作。
